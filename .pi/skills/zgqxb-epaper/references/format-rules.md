# 模式B：一篇一个文件（知识库格式）

## 目录结构

```
0_收件箱/
└── YYYY-MM-DD/
    ├── 01版/
    │   ├── 文章标题.md
    │   └── 另一篇文章.md
    ├── 02版/
    └── ...
```

## Frontmatter 字段

```yaml
---
title: 文章完整标题
date: 2026-01-01
edition: 01版
column:   # 无栏目则留空
author: 作者全名（多人用顿号分隔）
region:  # 无具体地区则留空
words: 数字
source: 中国气象报
yt: 引题（无则留空）
fb: 副题（无则留空）
---
```

### 关键规则

| 字段 | 无值时的写法 | 禁忌 |
|------|-------------|------|
| `column` | **留空** | 不写"无"，不用版面名代替 |
| `region` | **留空** | 不写"（中国气象局）""（全国）"等 |
| `author` | 留空 | 多人用顿号(、)分隔，不用空格或逗号 |

## 栏目（column）规则

- **栏标是栏目判断的唯一证据**：只能依据本期版面图中实际可见的栏目条/栏目标识，并将栏标文字与 `KNOWN_COLS` 做严格标准名称比对后填写。
- **正文、文章标题、引题、副题、主题、版面名、历史记录、位置邻近和栏目库本身，都不能证明栏目存在**；不得从正文内容反推栏目。
- 文章标题清单只允许用于：在栏标已经确认后，按版面位置确定该栏标正下方的文章归属；不能用来产生栏目候选。
- 看不到明确栏标，或栏标文字无法与栏目库严格匹配，`column` 留空。
- **引题（yt）和栏目是两回事**，不可混用。

### 栏目标识判断

- 版面图中有明确的带底色、边框或独立版式的栏目条，且文字严格命中栏目库 → 栏目
- 文章上方有带“·”的文字或“【栏目名】”标签，只有在版面图中明确呈现为栏标时才算栏目
- 引题以“——”开头或标注“本报通讯员”等 → 不是栏目证据
- 版面专题标题（如“畅想十五五”“奔涌向未来”）→ 不是栏目证据
- 专家署名文章、编者按 → 通常无栏目

### 03版（党建）栏目标注判例

| 文章 | 正确栏目 | 常见误标（视觉模型） |
|------|---------|-------------------|
| 上海青浦：守心中的"山" | 强化政治机关意识走好第一方阵·学思践悟 | "守心中的山"（这是文章标题） |

### 02版栏目标注

02版（综合）中，"短讯速递"是一个合集栏目，覆盖所有简短消息。其他文章各有独立栏目。若无栏目标识则留空。

## 地区（region）规则

| 场景 | 写法 | 示例 |
|------|------|------|
| 中国气象局本级事项 | **留空** | 气象导航推进会、政商座谈会 |
| 跨省/跨区域 | **留空** | 平蓟三兴（京津冀四地）|
| 全国性话题 | **留空** | 时评、图片新闻、卷首语/编者按 |
| 历史人物 | **留空** | 张乃召 |
| 省级领导调研 | 省名 | 河北、广西、贵州 |
| 市县事项 | 省+市(+区/县) | 新疆乌鲁木齐达坂城、山东济南平阴 |
| 国际合作 | 国名 | 埃塞俄比亚、蒙古国 |
| 可精确到区/县 | 省+市(+区/县) | 江西抚州东乡区、山东威海荣成石岛 |

从正文提取，不臆测。

## 正文内容

- **禁止截断**：获取完整全文，禁止加 `[:300]` 等长度限制
- **禁止写摘要**：不要用"（正文见epaper）""（全文略）"等占位符
- 报眉（本报讯/本报通讯员/本报记者）和落款（XXX整理）一并保留
- 图像类（图片新闻）写图片说明文字
- 正文开头直接是 `# 标题`，不重复显示引题/副题

## 作者（author）规则

- 多名作者用**顿号（、）**分隔
- 口述者与整理者均列入作者，用顿号分隔（如"龚建东、王亮"）
- "本报记者""本报通讯员"等前缀不写入 author 字段，保留在正文中
- 作者未知则留空

## 正文清洗

```python
import re
c = content_raw
c = c.replace('&nbsp;&nbsp;', ' ')        # 缩进转空格
c = c.replace('&nbsp;', '')               # 其他空白占位
c = c.replace('\xa0', '')                 # 不换行空格
c = re.sub(r'<[^>]+>', '', c)             # 去HTML标签
c = c.strip()
```
