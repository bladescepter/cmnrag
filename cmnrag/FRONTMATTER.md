# 中国气象报稿件 Frontmatter 说明

本目录下按刊期保存的 Markdown 文件为已清洗的《中国气象报》稿件。每篇开头的 YAML frontmatter 是**结构化档案字段**，不是正文内容。本文档适用于现有及后续增补的所有刊期资料。

使用这些文件建立检索系统时：

- “有多少篇”“列出哪些”“只看某个栏目/地区/版面/日期/作者”等问题，必须先按下列字段做数据库精确筛选；不能只依赖向量检索或大模型概括。
- “共同特点是什么”“有哪些做法”“对比不同地区经验”等内容性问题，应在结构化筛选后，再检索和归纳正文。
- 所有字段值保留原文；没有值时为空字符串，不应自行补写、猜测或将空值当作“全国”。

## 字段总表

| 字段 | 含义 | 值与查询规则 |
|---|---|---|
| `type` | 稿件类型 | 当前固定为 `报道`。 |
| `source` | 文章来源 | 当前固定为 `中国气象报`。 |
| `title` | 主标题 | 稿件正式标题。可用于标题检索、展示和引用。 |
| `subtitle` | 副题 | 仅部分稿件存在；应与主标题共同展示和全文检索，但不替代 `title`。 |
| `author` | 作者 | 仅保留作者姓名，多个姓名以空格分隔；不含“本报记者”“通讯员”等职称前缀。为空表示未提取到可用作者，不代表无署名。 |
| `date` | 出版日期 | 格式为 `YYYY-MM-DD`。时间范围查询必须按此字段筛选。 |
| `page` | 报纸版面 | `一版`、`二版`、`三版`、`四版`之一。用户问“第几版”“版面”对应此字段。 |
| `theme` | 版面主题 | 电子版 API 的版面主题原值，如 `要闻`、`综合`、`科技`、`党建`、`副刊`、`科普`、`特别策划` 等。它不是栏目。 |
| `edition_type` | 版别 | `常规版` 或 `策划版`。由 `theme` 判定，用于粗粒度筛选；它不是 `theme` 或 `column` 的同义词。 |
| `headline` | 是否头条 | 布尔值 `true` / `false`。一版可有双头条；策划版也可能没有头条。 |
| `image` | 是否图片新闻 | 仅图片新闻标为 `true`；字段不存在时按 `false` 处理。图片新闻的正文通常是图片说明，不应按普通长文理解。 |
| `column` | 栏目 | 报纸编排中的具体栏目或系列报道全称，如 `科普看台`、`短讯速递`、`我在现场`。空值表示该稿未标注栏目。它不是 `theme`、`page`、标题引题或正文主题。 |
| `region` | 稿件主体地区 | 稿件报道、聚焦或主要发生的行政区域，尽可能采用完整路径，如 `河北省邢台市沙河市`。空值表示中国气象局本级、全国性、跨省/跨区域或无法唯一归属的稿件；不代表正文没有出现地名。 |

## 最关键的字段边界

### `column`（栏目）

`column` 是报纸的编排字段，不等于主题、关键词或正文提及内容。

```yaml
column: 科普看台
```

- “科普看台有几篇”“我和天气打交道有哪些稿件”必须按 `column` 精确筛选。
- 用户输入的栏目名可能是全称、简称、连续片段或不完整说法。系统可用全部非空栏目值作为候选集解析名称；只有唯一对应到一个完整栏目值后，才能执行统计或列举。
- 不能因为正文出现“科普”“防灾减灾”等词，就把稿件计入某栏目。
- `column` 为空不等于没有主题，也不等于不属于任何版面。

长栏目示例：

```yaml
column: “人民至上、生命至上”主题实践活动 发挥气象防灾减灾第一道防线作用
```

用户说“防灾减灾第一道防线栏目”时，系统应将其与全部栏目值匹配，唯一命中上述完整值后再查询；不应以关键词搜索结果直接计数。

### `region`（主体地区）

`region` 表示稿件主体所在地，而不是正文中所有被提及的地点。

```yaml
region: 河北省邢台市沙河市
```

- “有多少河北报道”“列出河北的稿件”应匹配 `region` 为 `河北省` 或以 `河北省` 开头的值。
- “哪些稿件提到河北”是全文检索问题，结果可能多于“河北报道”。
- 标题中地名通常是主体地区；但全国性、跨省性、中央层面的报道即使提到多个省份，`region` 仍可能为空。
- 查询地区时，`河北` 可作为 `河北省` 的用户输入别称；数据库实际值保留带行政区后缀的原值。

### `theme`、`edition_type` 与 `column` 的区别

```yaml
theme: 科普
edition_type: 策划版
column: 科普看台
```

三者不是一回事：

- `theme`：版面主题；
- `edition_type`：常规版/策划版的归类；
- `column`：具体栏目或系列名称。

用户问“科普版”“科普主题”“科普栏目”含义不同：

- “科普主题”优先筛选 `theme: 科普`；
- “科普看台栏目”筛选 `column: 科普看台`；
- “科普文章”通常是内容检索，不应强行等同于任一字段。

## 查询规则

### 结构化问题：必须精确筛选

| 用户问题 | 正确字段/规则 |
|---|---|
| 防灾减灾第一道防线栏目有几篇？ | 先将简称唯一映射到完整 `column` 值，再 `column = 完整值` 计数。 |
| 7 月有我和天气打交道栏目吗？ | `column = 我在天气打交道` 不正确；应先候选匹配到 `我和天气打交道`，再精确查询。 |
| 河北有多少报道？ | `region = 河北省` 或 `region` 以 `河北省` 开头。 |
| 7 月 29 日一版有哪些头条？ | `date = 2026-07-29 AND page = 一版 AND headline = true`。 |
| 邹伟写了哪些稿件？ | 作者字段按姓名边界匹配 `author`，不可用姓名子串误匹配。 |
| 哪些是图片新闻？ | `image = true`；缺少 `image` 字段按 `false`。 |

### 内容问题：先筛选，再读正文

例如“河北的防灾减灾第一道防线报道有哪些共同做法？”：

1. 先解析并精确筛选 `region` 和 `column`；
2. 只在筛选出的正文范围内检索、分块和归纳；
3. 回答应附标题、日期、版面等来源，不得编造未出现在正文中的事实。

## 完整示例

```yaml
---
type: 报道
source: 中国气象报
title: 汛期防“菌”守住健康
author:
date: 2026-07-29
page: 四版
theme: 科普
edition_type: 策划版
headline: true
column: 科普看台
region:
---
```

它表示：一篇 2026 年 7 月 29 日刊于四版、主题为科普、属于策划版且为头条的《中国气象报》报道；栏目是“科普看台”；没有唯一主体地区；作者字段为空。

## 数据范围与限制

- 本文档适用于本目录现有及后续增补的所有刊期稿件。
- `region` 是用于档案检索的主体地区判断，不是全文地名实体清单。
- `column` 以已人工确认的原始全称为准；对于简称、错别字或含混问法，系统应先显示候选或请求确认，不能自行把多个栏目合并统计。
- 本文件解释数据含义，但不替代数据库筛选逻辑；说明被模型读到，不等于模型可保证全量、精确查询。
